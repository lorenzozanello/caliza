# ProductCard

Tarjeta de pieza en la colección. Foto 3:2 sobre `fondo-producto`, estado, nombre, precio y materiales.

- Fotos de estudio con fondo blanco: clase `is-studio` (se funden con multiplicar).
- Al pasar el cursor la foto se acerca y sube la acción rápida (`cz-product-card__quick`): "Configurar pieza" o "Agregar al carrito". En pantallas táctiles la acción queda siempre visible.
- Precio: "Desde $ X" para piezas configurables, "$ X" para entrega inmediata, "Cotizar" para piezas de autor.
- Materiales siempre nombrados en orden: la piedra primero.
- Nombres y precios de la vista previa son de ejemplo.

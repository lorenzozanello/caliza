# Field

Campo de formulario con etiqueta siempre visible y ayuda debajo.

- Fondo `papel`, borde fino, sin radio. El borde pasa a `carbon` al enfocar.
- `cz-field--error`: borde y ayuda en `error`, con un texto que dice cómo corregir.
- Tamaño de letra 16px en el campo para que el móvil no haga zoom.
- El marcador de posición ayuda, nunca reemplaza la etiqueta.

# PaymentChoice

Elección de plan y método de pago en el checkout, con el resumen "Hoy pagas".

- Planes: Pago completo y Anticipo 50% (el saldo se cobra antes del despacho).
- Métodos: Tarjeta, PSE, Nequi, Botón Bancolombia y pago a cuotas si la pasarela lo permite.
- El botón de pago dice el monto y el método exactos. "Hoy pagas" cuenta hasta el nuevo valor al cambiar de plan.
- Montos de ejemplo.

# MaterialRow

Lista tipográfica de materiales: "La piedra y sus aliados". La piedra siempre primero.

- Al pasar el cursor por una fila, las demás se atenúan (`manifiesto-apagado`), la fila se desplaza y una imagen del material sigue al cursor.
- En móvil, cada fila muestra una miniatura fija en lugar de la imagen que sigue al cursor.

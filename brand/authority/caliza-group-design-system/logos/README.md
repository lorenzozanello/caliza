# Logos

Vectoriales, con el texto convertido a curvas (Playfair Display 400 y Montserrat 400). Colores fijos dentro del SVG: no heredan `color`.

- `caliza-group.svg` — Versión principal: marine-ink #18343C con filete terracotta #AE7256. Sobre limewash, sand o blanco.
- `caliza-group-inversa.svg` — Versión inversa: limewash #F2EADC con filete terracotta. Sobre marine-ink o fotografía oscura.
- `caliza-group-monocroma.svg` — Una sola tinta, marine-ink. Impresión a una tinta, grabado, sellos.
- `caliza-stone-design.svg`, `caliza-living-design.svg`, `caliza-stone-care.svg` — Lockups de submarca: símbolo terracotta, CALIZA y descriptor en marine-ink. Sobre fondos claros.
- `…-inversa.svg` — Los mismos lockups con texto limewash, para marine-ink.

Redibujados en vector a partir del manual de marca (imagen de referencia en `Referencia/`). Si existen archivos maestros del estudio de diseño, reemplázalos por esos.

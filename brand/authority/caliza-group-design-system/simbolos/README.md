# Símbolos

Símbolos de submarca, construidos sobre la retícula de la sección "Geometría" del manual.

- `simbolo-stone-design.svg` — Disco de tres cuartos con semianillo y cuarto de anillo concéntricos. Terracotta #AE7256.
- `simbolo-living-design.svg` — Arco de medio punto. Terracotta.
- `simbolo-stone-care.svg` — Estrella de cuatro puntas de lados cóncavos. Terracotta.
- `…-limewash.svg` — Las mismas formas en limewash #F2EADC, para usar sobre terracotta, marine-ink o fotografía.

Una sola tinta por archivo; para otro color usa el componente BrandSymbol, que hereda `color`.

# CALIZA GROUP — Sistema de diseño

Empieza por **`AI_BRIEF.md`**: es la referencia completa y autosuficiente (reglas, tokens, tipografía, logos, componentes, voz y fotografía).

- `MANUAL.md` — manual de marca en prosa.
- `tokens/` — `tokens.json` (fuente de verdad), `tokens.css` (variables, @font-face, clases de texto), `tailwind.preset.js`.
- `fonts/` — Playfair Display y Montserrat en woff2 (licencia OFL).
- `logos/`, `simbolos/` — SVG vectoriales.
- `imagen/`, `referencia/` — dirección de arte y el manual original.
- `components/` — componentes React 18 (`bundle.js` → `window.Caliza`), estilos, tipos y una guía por componente; React incluido en `components/lib/`.
- `demo.html` — página de demostración que funciona sin conexión; ábrela en un navegador.

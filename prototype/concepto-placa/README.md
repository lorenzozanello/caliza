# Concepto «La placa»

Dirección de experiencia propuesta el 1 de octubre de 2026, en revisión. La piedra se genera en vivo con WebGL2 (`stone.js`), así que no depende de fotografías.

- **Hero:** una placa única por visita (blanco veteado, nero o travertino). El cursor la moja, como hacen los marmoleros para ver el color real antes de pulir.
- **Book-match:** al hacer scroll, dos cortes del mismo bloque se abren como un libro.
- **Una piedra, tres oficios:** la misma placa en pulido (Stone), apomazado (Design) y un antes/después de restauración (Care).
- **Patio de placas:** placas numeradas que se arrastran con inercia.
- **Estratos:** las tres generaciones como capas de piedra.
- **Piezas:** índice editorial con la foto siguiendo al cursor.

`index.html` lleva el marcador `/*__STONE__*/`, donde se inserta `stone.js` al publicar.
